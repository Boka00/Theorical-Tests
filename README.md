# 🎓 Front-End თეორიული გამოცდის სიმულაცია (Junior Developer)

თანამედროვე, ინტერაქტიული ვებ-აპლიკაცია Front-End დეველოპერებისთვის რეალური თეორიული გამოცდის სიმულაციისთვის.

## 🚀 ტექნოლოგიური სტეკი
- **React 18** (Functional Components, Custom Hooks)
- **TypeScript** (Strict Type-Safety)
- **Tailwind CSS** (Utility-First Styling, Responsive, Dark Theme)
- **Vite** (Next Generation Frontend Tooling)
- **Lucide Icons**

## 💻 ლოკალურად გაშვება

1. **რეპოზიტორიის კლონირება:**
   ```bash
   git clone https://github.com/Boka00/Theorical-Tests.git
   cd Theorical-Tests
   ```

2. **დამოკიდებულებების ინსტალაცია:**
   ```bash
   npm install
   ```

3. **დეველოპმენტ სერვერის გაშვება:**
   ```bash
   npm run dev
   ```
   გახსენით ბრაუზერში: `http://localhost:5173`

4. **პროდაქშენ ბილდი:**
   ```bash
   npm run build
   ```
